### 1.3 握手拦截器（从 query 取 token 鉴权）
浏览器 WebSocket 不能自定义 Authorization 头，所以 token 放 `?token=xxx`，握手时解析并把 userId 放进 attributes：

```java
@Component
@RequiredArgsConstructor
public class JwtHandshakeInterceptor implements HandshakeInterceptor {
    private final JwtUtil jwtUtil;
    private final RedisTemplate<String,Object> redisTemplate;

    @Override
    public boolean beforeHandshake(ServerHttpRequest request, ServerHttpResponse response,
                                   WebSocketHandlerContainer ws, Map<String,Object> attrs) {
        // 简化：从 URI query 解析 token
        String query = request.getURI().getQuery();
        String token = parseQuery(query).get("token");
        if (token != null) {
            try {
                Claims c = jwtUtil.parse(token);
                Long uid = Long.valueOf(c.getSubject());
                String device = c.get("device", String.class);
                Object cached = redisTemplate.opsForValue()
                    .get("mars:token:access:" + uid + ":" + device);
                if (cached != null && c.getId().equals(cached.toString())) {
                    attrs.put("userId", uid);
                    attrs.put("eventId", parseQuery(query).get("eventId"));
                    return true;
                }
            } catch (Exception ignored) {}
        }
        return true;   // 允许游客看弹幕，但发送时要求登录
    }
    @Override public void afterHandshake(ServerHttpRequest r, ServerHttpResponse s,
                                         WebSocketHandler h, Exception e) {}
}
```

### 1.4 弹幕 Handler（连接管理 + 限流 + 过滤 + 广播）
路径：`community/ws/DanmakuHandler.java`

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class DanmakuHandler extends TextWebSocketHandler {

    // 每个场次一组会话（单体内存；多实例用 Redis Pub/Sub，见第3节）
    private static final Map<Long, Set<WebSocketSession>> ROOMS = new ConcurrentHashMap<>();

    private final SensitiveWordFilter sensitiveWordFilter;
    private final RedisService redis;
    private final DanmakuRedisPublisher publisher;

    @Override
    public void afterConnectionEstablished(WebSocketSession session) {
        Long eventId = eventId(session);
        ROOMS.computeIfAbsent(eventId, k -> ConcurrentHashMap.newKeySet()).add(session);
    }

    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) {
        Long userId = (Long) session.getAttributes().get("userId");
        if (userId == null) { send(session, error("请先登录")); return; }
        Long eventId = eventId(session);

        DanmakuDTO dto = JSON.parseObject(message.getPayload(), DanmakuDTO.class);

        // ① 限流：每人每秒1条
        String rk = "mars:rate:danmaku:" + userId;
        Long n = redis.incr(rk);
        if (n == 1) redis.expire(rk, 1);
        if (n > 1) { send(session, error("发言太快了")); return; }

        // ② 敏感词过滤
        String clean = sensitiveWordFilter.filter(dto.getContent());
        if (clean.isBlank()) { send(session, error("内容含违规词")); return; }

        // ③ 广播（先发到 Redis 频道，由订阅者统一推各实例；单体也可直接 localBroadcast）
        publisher.publish(eventId, new DanmakuMessage(userId, dto.getNickname(), clean, dto.getColor()));
    }

    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
        Long eventId = eventId(session);
        Set<WebSocketSession> set = ROOMS.get(eventId);
        if (set != null) set.remove(session);
    }

    /** 本实例向某场次所有会话推送 */
    public void localBroadcast(Long eventId, DanmakuMessage msg) {
        Set<WebSocketSession> set = ROOMS.getOrDefault(eventId, Set.of());
        String json = JSON.toJSONString(msg);
        for (WebSocketSession s : set) {
            if (s.isOpen()) {
                try { s.sendMessage(new TextMessage(json)); }
                catch (IOException e) { log.warn("弹幕推送失败", e); }
            }
        }
    }

    private Long eventId(WebSocketSession s) {
        Object v = s.getAttributes().get("eventId");
        return v == null ? null : Long.valueOf(v.toString());
    }
    private void send(WebSocketSession s, String text) {
        try { s.sendMessage(new TextMessage(text)); } catch (IOException ignored) {}
    }
}
```

## 2. 敏感词 DFA 过滤

DFA（确定有限自动机）：把敏感词库构建成字符树，匹配时一次扫描即可命中所有词，比反复 `contains` 快得多。

路径：`community/filter/SensitiveWordFilter.java`

```java
@Slf4j
@Component
public class SensitiveWordFilter {

    /** 词树根节点：字符 -> (是否词尾, 下一层) */
    private final Map<Character, Object> root = new HashMap<>();
    private static final String END_FLAG = "isEnd";

    @PostConstruct
    public void init() {
        // 实际从 cm_sensitive_word 表加载；学习期内置几个
        List<String> words = List.of("黄牛", "退票中介", "假票");
        words.forEach(this::addWord);
    }

    @SuppressWarnings("unchecked")
    private void addWord(String word) {
        Map<Character, Object> node = root;
        for (int i = 0; i < word.length(); i++) {
            char c = word.charAt(i);
            Object next = node.get(c);
            if (!(next instanceof Map)) {
                Map<Character, Object> child = new HashMap<>();
                node.put(c, child);
                node = child;
            } else {
                node = (Map<Character, Object>) next;
            }
            if (i == word.length() - 1) node.put(END_FLAG.charAt(0), true);
        }
    }

    /** 命中则替换为等长 *；无命中返回原文 */
    public String filter(String text) {
        if (text == null) return "";
        char[] chars = text.toCharArray();
        for (int i = 0; i < chars.length; i++) {
            int len = matchLen(chars, i);
            if (len > 0) {
                for (int k = i; k < i + len; k++) chars[k] = '*';
                i += len - 1;
            }
        }
        return new String(chars);
    }

    @SuppressWarnings("unchecked")
    private int matchLen(char[] chars, int start) {
        Map<Character, Object> node = root;
        int len = 0, matched = 0;
        for (int i = start; i < chars.length; i++) {
            Object next = node.get(chars[i]);
            if (!(next instanceof Map)) break;
            len++;
            node = (Map<Character, Object>) next;
            if (Boolean.TRUE.equals(node.get(END_FLAG.charAt(0)))) matched = len;
        }
        return matched;   // 命中词长度（取最长匹配）
    }
}
```

评论内容（`cm_comment`）入库前同样调用 `filter`，后台可做"待审核/替换"策略。评论树（parent_id/root_id）、点赞用 Redis Hash 计数后定时回写，表结构参考总设计文档，CRUD 与 FAQ 同套路，这里不重复。

## 3. 弹幕集群广播（Redis Pub/Sub）

多实例时 A 用户连到实例 1、B 用户连到实例 2，内存 ROOMS 互不相通。用 Redis 发布订阅打通：

发送侧 `DanmakuRedisPublisher`：
```java
@Component
@RequiredArgsConstructor
public class DanmakuRedisPublisher {
    private final RedisTemplate<String,Object> redisTemplate;
    public void publish(Long eventId, DanmakuMessage msg) {
        redisTemplate.convertAndSend("mars:channel:danmaku:" + eventId, msg);
    }
}
```

接收侧（每个实例都订阅所有弹幕频道，收到后推本实例会话）：
```java
@Configuration
@RequiredArgsConstructor
public class DanmakuSubscriberConfig {
    private final RedisMessageListenerContainer container;
    private final DanmakuHandler danmakuHandler;

    @Bean
    public MessageListenerAdapter danmakuListener() {
        // 用 PatternTopic 订阅所有场次频道；消息带 eventId
        MessageListener listener = (message, pattern) -> {
            String channel = new String(message.getChannel());
            Long eventId = Long.valueOf(channel.substring(channel.lastIndexOf(':') + 1));
            DanmakuMessage msg = (DanmakuMessage) new GenericJackson2JsonRedisSerializer()
                .deserialize(message.getBody());
            danmakuHandler.localBroadcast(eventId, msg);
        };
        container.addMessageListener(listener, new PatternTopic("mars:channel:danmaku:*"));
        return null;
    }
}
```

> 需要注册一个 `RedisMessageListenerContainer` Bean（Spring Data Redis 提供，连接工厂用 LettuceConnectionFactory）。这样不管部署几个实例，弹幕都能全员收到。第 8 卷上微服务后也可换成 RabbitMQ fanout。

### 4.2 领取（Redis 原子校验一人一券 + 库存）
```java
@Service
@RequiredArgsConstructor
public class CouponService {
    private final StringRedisTemplate redis;
    private final CouponTemplateMapper templateMapper;
    private final UserCouponMapper userCouponMapper;

    @Transactional(rollbackFor = Exception.class)
    public void receive(Long userId, Long tplId) {
        CouponTemplate t = templateMapper.selectById(tplId);
        if (t == null || t.getStatus() != 1) throw new BusinessException(7001,"券不存在或已下架");

        // 一人一券（per_user_limit=1 的场景）
        Boolean firstUser = redis.opsForValue().setIfAbsent(
            "mars:coupon:" + tplId + ":user:" + userId, "1", 30, TimeUnit.DAYS);
        if (Boolean.FALSE.equals(firstUser)) throw new BusinessException(7002,"您已领取过该券");

        // 库存原子扣减（券总量放 Redis；预热时写入）
        Long left = redis.opsForValue().decrement("mars:coupon:" + tplId + ":stock");
        if (left != null && left < 0) {
            redis.opsForValue().increment("mars:coupon:" + tplId + ":stock"); // 回补
            redis.delete("mars:coupon:" + tplId + ":user:" + userId);
            throw new BusinessException(7003,"券已被领完");
        }

        // DB 唯一索引做最终兜底（并发穿透Redis极小概率时）
        try {
            UserCoupon uc = new UserCoupon();
            uc.setTemplateId(tplId); uc.setUserId(userId); uc.setStatus("UNUSED");
            uc.setValidStart(LocalDateTime.now());
            uc.setValidEnd(LocalDateTime.now().plusDays(t.getValidDays()));
            userCouponMapper.insert(uc);
        } catch (DuplicateKeyException dup) {
            throw new BusinessException(7002,"您已领取过该券");
        }
    }

    public List<UserCouponVO> myCoupons(Long userId, String status) { /* 条件查 + 模板信息组装 */ }
}
```

## 5. 优惠券接入价格引擎与下单

### 5.1 选券试算接口
`POST /orders/price-preview`：入参 eventId、items、userCouponId；服务端查券的归属/有效期/适用范围/门槛，算出优惠后金额返回（给订单确认页展示）。

### 5.2 改造 PriceEngine
`calculate` 增加重载，接收 `UserCoupon + CouponTemplate`：
```java
public OrderPrice calculate(List<PriceLine> lines, UserCoupon uc, CouponTemplate tpl) {
    OrderPrice base = calculate(lines);             // 先算原价+服务费
    BigDecimal discount = BigDecimal.ZERO;
    if (uc != null && tpl != null && "UNUSED".equals(uc.getStatus())) {
        // 校验适用范围（全场/指定场次/票档）与门槛
        boolean scopeOk = "ALL".equals(tpl.getScope())
            || (scopeMatch(lines, tpl));
        boolean thresholdOk = base.getTotalAmount().compareTo(tpl.getThreshold()) >= 0;
        if (scopeOk && thresholdOk) {
            discount = switch (tpl.getType()) {
                case "FULL_CUT" -> tpl.getFaceValue();
                case "CASH" -> tpl.getFaceValue();
                case "DISCOUNT" -> base.getTotalAmount()
                        .multiply(BigDecimal.ONE.subtract(
                            tpl.getFaceValue().divide(BigDecimal.TEN, 2, RoundingMode.HALF_UP)));
                default -> BigDecimal.ZERO;
            };
            // 优惠不超过票价合计
            if (discount.compareTo(base.getTotalAmount()) > 0) discount = base.getTotalAmount();
        }
    }
    BigDecimal pay = base.getTotalAmount().add(base.getServiceAmount()).subtract(discount);
    return new OrderPrice(base.getTotalAmount(), base.getServiceAmount(), discount, pay.max(BigDecimal.ZERO));
}
```

### 5.3 下单核销券
第 3 卷 `createOrder` 增加 `userCouponId`：
- 用 `UPDATE pm_user_coupon SET status='USED', order_no=? WHERE id=? AND user_id=? AND status='UNUSED'` 条件更新，affected=0 说明券不可用/被并发使用，抛异常回滚；
- 订单取消/退款时把券退回为 UNUSED（清 order_no）。

> 这样券从「领取防超」到「下单互斥核销」到「退款退回」闭环，且全程条件更新保证不被一单多用。

## 7. 秒杀：Redis 预减 + MQ 异步下单

高并发核心场景。思路：**Redis 挡住并发，MQ 把瞬时写削成平稳写，DB 按能力消费**。

### 7.2 秒杀 Lua（判重 + 扣余量一步完成）
路径：`promotion/seckill/SeckillScript.java`
```lua
-- KEYS[1]=库存 KEYS[2]=用户标记
-- ARGV[1]=userId ARGV[2]=qty ARGV[3]=活动开始epoch ARGV[4]=结束epoch ARGV[5]=当前epoch
if tonumber(ARGV[5]) < tonumber(ARGV[3]) then return -3 end   -- 未开始
if tonumber(ARGV[5]) > tonumber(ARGV[4]) then return -4 end   -- 已结束
if redis.call('EXISTS', KEYS[2]) == 1 then return -2 end      -- 已抢过
local left = tonumber(redis.call('GET', KEYS[1]) or '0')
if left < tonumber(ARGV[2]) then return -1 end                -- 售罄
redis.call('DECRBY', KEYS[1], ARGV[2])
redis.call('SET', KEYS[2], '1')
return left - tonumber(ARGV[2])                              -- 返回剩余
```

### 7.4 消费者按能力速率建单
```java
@RabbitListener(queues = "q.seckill.order")
public void on(String body, Channel channel, @Header(AmqpHeaders.DELIVERY_TAG) long tag) throws IOException {
    SeckillMessage msg = JSON.parseObject(body, SeckillMessage.class);
    try {
        String orderNo = orderService.createSeckillOrder(msg);  // 内部再校验活动/库存/幂等
        redis.set("mars:seckill:result:"+msg.getTicket(), orderNo, 300);
        channel.basicAck(tag,false);
    } catch (Exception e) {
        // 建单失败：回补 Redis 库存和用户标记
        redis.opsForValue().increment("mars:seckill:"+msg.getActId()+":stock");
        redis.delete("mars:seckill:"+msg.getActId()+":user:"+msg.getUserId());
        redis.set("mars:seckill:result:"+msg.getTicket(),"FAIL",300);
        channel.basicAck(tag,false);   // 业务失败已补偿，确认消息避免无限重试
    }
}
```

前端：执行后轮询 `GET /seckill/result?ticket=`，得到 QUEUED/订单号/FAIL。配合网关/接口限流（第 7/8 卷 Sentinel）和图形验证码防机器。

```java
@Service
@RequiredArgsConstructor
public class SongSearchService {
    private final ElasticsearchOperations operations;

    public SearchPageResult<SongDoc> search(String keyword, String album, int page, int size) {
        NativeQuery q = NativeQuery.builder()
            .withQuery(qb -> qb.bool(b -> {
                if (keyword != null && !keyword.isBlank()) {
                    b.must(m -> m.multiMatch(mm -> mm
                        .query(keyword)
                        .fields("nameZh^3","nameEn^2","artistName")));
                }
                if (album != null) b.filter(f -> f.term(t -> t.field("album").value(album)));
                b.should(s -> s.matchAll(ma -> ma));
            }))
            .withSort(Sort.by(Sort.Order.by("_score")))
            .withPageable(PageRequest.of(page-1, size))
            .build();
        SearchHits<SongDoc> hits = operations.search(q, SongDoc.class);
        return new SearchPageResult<>(hits.get().map(SearchHit::getContent).toList(),
                hits.getTotalHits(), page, size);
    }
}
```

```java
@Service
@RequiredArgsConstructor
public class FileService {
    private final MinioClient client;
    private final MinioProps props;

    /** 上传到公开 bucket，返回可访问URL */
    public String uploadPublic(MultipartFile file) {
        try {
            String ext = FilenameUtils.getExtension(file.getOriginalFilename());
            String object = "upload/" + LocalDate.now() + "/"
                + UUID.randomUUID() + (ext.isBlank() ? "" : "." + ext);
            ensureBucket(props.getBucketPublic());
            client.putObject(PutObjectArgs.builder()
                .bucket(props.getBucketPublic()).object(object)
                .stream(file.getInputStream(), file.getSize(), -1)
                .contentType(file.getContentType())
                .build());
            return props.getEndpoint() + "/" + props.getBucketPublic() + "/" + object;
        } catch (Exception e) {
            throw new BusinessException(8001, "文件上传失败: " + e.getMessage());
        }
    }

    /** 私有 bucket 生成限时签名下载URL（如票品附件、发票） */
    public String presignedGet(String object) {
        try {
            return client.getPresignedObjectUrl(GetPresignedObjectUrlArgs.builder()
                .method(Method.GET).bucket(props.getBucketPrivate()).object(object)
                .expiry(10, TimeUnit.MINUTES).build());
        } catch (Exception e) { throw new BusinessException(8002,"生成下载链接失败"); }
    }

    private void ensureBucket(String bucket) throws Exception {
        boolean exists = client.bucketExists(BucketExistsArgs.builder().bucket(bucket).build());
        if (!exists) client.makeBucket(MakeBucketArgs.builder().bucket(bucket).build());
    }
}
```

Controller：
```java

    return Result.success(fileService.uploadPublic(file));
}
```

> 大文件/视频建议用「后端只发预签名 PUT URL，前端直传 MinIO」的方式，避免流量过应用服务器；本卷先掌握标准上传。

## 11. 操作日志 AOP（@OperationLog）

### 11.1 注解
路径：`common/annotation/OperationLog.java`
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface OperationLog {
    String module();                    // 模块
    String action();                    // 动作
    String bizIdSpel() default "";      // SpEL 取业务id，如 "#orderNo"
}
```

### 11.2 切面
路径：`common/aspect/OperationLogAspect.java`
```java
@Slf4j
@Aspect
@Component
@RequiredArgsConstructor
public class OperationLogAspect {

    private final OperationLogMapper logMapper;
    private final ObjectMapper objectMapper;
    private final SpelExpressionParser parser = new SpelExpressionParser();

    /** 线程池异步落库，避免影响主接口性能 */
    private final Executor executor = Executors.newFixedThreadPool(2);

    @Around("@annotation(opLog)")
    public Object around(ProceedingJoinPoint pjp, OperationLog opLog) throws Throwable {
        long start = System.currentTimeMillis();
        Object result = null;
        String error = null;
        try {
            result = pjp.proceed();
            return result;
        } catch (Throwable t) {
            error = t.getMessage();
            throw t;
        } finally {
            long cost = System.currentTimeMillis() - start;
            SysOperationLog entity = new SysOperationLog();
            entity.setModule(opLog.module());
            entity.setAction(opLog.action());
            entity.setCostMs((int) cost);
            entity.setSuccess(error == null ? 1 : 0);
            entity.setErrorMsg(error);
            entity.setOperator(Optional.ofNullable(UserContext.getUserId())
                .map(String::valueOf).orElse("anonymous"));
            try {
                entity.setParams(objectMapper.writeValueAsString(pjp.getArgs()).length() > 2000
                    ? "..." : objectMapper.writeValueAsString(pjp.getArgs()));
            } catch (Exception ignored) {}
            if (!opLog.bizIdSpel().isBlank()) {
                try {
                    EvaluationContext ctx = new StandardEvaluationContext();
                    String[] names = ((MethodSignature) pjp.getSignature()).getParameterNames();
                    Object[] args = pjp.getArgs();
                    for (int i = 0; i < names.length; i++) ctx.setVariable(names[i], args[i]);
                    entity.setBizId(parser.parseExpression(opLog.bizIdSpel()).getValue(ctx, String.class));
                } catch (Exception ignored) {}
            }
            executor.execute(() -> { try { logMapper.insert(entity); } catch (Exception ignored) {} });
        }
    }
}
```

启动类加 `@EnableAspectJAutoProxy`（spring-boot-starter-aop 引入后通常自动）。在 Controller/Service 方法上使用：
```java
@OperationLog(module="订单", action="取消订单", bizIdSpel="#orderNo")
@PostMapping("/{orderNo}/cancel")
public Result<Void> cancel(...) { ... }
```

`sys_operation_log` 表：id、module、action、biz_id、operator、params、success、error_msg、cost_ms、create_time。后台提供日志查询页（按模块/操作人/时间筛选）。

> 同样手法可以做 `@RateLimit`（Redis 滑动窗口/Lua）、`@DataScope`（拼数据权限 SQL）、`@DistributedLock`（Redisson），本卷先掌握 AOP 通用套路，第 7 卷把它们沉淀成自研 starter。

## 本卷联调与验收

- 弹幕：开两个浏览器（一个登录 A、一个登录 B）进入同场次页，A 发弹幕 B 实时收到；连发触发"发言太快"；敏感词被替换为 `*`。
- 优惠券：领取成功；重复领取被拒；用券下单金额正确扣减；券状态变 USED；取消订单券回退。
- 积分：签到一天只能一次；支付成功后积分增加并有流水。
- 秒杀：库存设 50，JMeter 200 并发，恰好 50 单、其余售罄/已抢过；一人一单；DB 不超卖；MQ 队列能看到削峰过程。
- 搜索：同步几首歌到 ES，中英文关键词都能命中；热词榜随搜索更新。
- 文件：上传图片返回 URL 可访问；私有对象签名 URL 限时可下载。
- 导出：管理员可导出订单 xlsx，普通用户 403。
- 操作日志：执行取消订单后，`sys_operation_log` 有记录，含耗时、操作人、成功与否、业务 id。

### 常见坑
| 现象 | 解决 |
|---|---|
| WebSocket 401 | 握手放行，token 走 query；setAllowedOriginPatterns |
| 弹幕多实例收不到 | 接 Redis Pub/Sub（第3节） |
| DFA 中文匹配错乱 | 按 char 遍历即可（Java char 对常用中文足够，生僻 emoji 用 codePoint） |
| 券超发 | Redis 原子扣减 + DB 唯一索引双保险 |
| 秒杀超卖 | 判重和扣库存必须同一 Lua；消费端再校验 |
| ES 中文一个字一分词 | 装 IK，字段 analyzer=ik_max_word、search_analyzer=ik_smart |
| ES 与 DB 数据不一致 | 管理端写库后同步 ES，或走 MQ/Canal |
| MinIO 上传 403 | bucket 不存在/策略；先 ensureBucket |
| AOP 不生效 | 同类自调用、非 Spring Bean、注解没打在 public 方法上 |
