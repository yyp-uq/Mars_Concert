## 1. 业务链路与表关系

```
场馆 show_venue 1───n 场次 show_event n───n 票档 show_ticket_tester
                                   │ 关联库存 show_event_tier（一场次多票档，各自库存）
购物车(Redis) ──提交──> 订单 ord_order 1───n 订单明细 ord_order_item
                              │
                         操作日志 ord_order_log（状态机每次迁移留痕）
```

- 场馆（南京汤山音乐谷）相对固定；场次（9-25/9-26…7 场）属于某场馆；
- 票档（¥380/680/980/1280）可定义为全局模板，但**每个场次卖哪些票档、各有多少库存**由 `show_event_tier` 决定；
- 本卷做「站票/数量库存」（不选具体座位），每买一张就是某场次某票档库存 -1。具体选座在第 4 卷。

## 4. 订单状态机（轻量自研）

路径：`order/statemachine/OrderStateMachine.java`

```java
package com.mars.concert.order.statemachine;

import com.mars.concert.common.exception.BusinessException;
import com.mars.concert.order.enums.OrderErrorCode;
import com.mars.concert.order.enums.OrderEvent;
import com.mars.concert.order.enums.OrderStatus;

import java.util.EnumMap;
import java.util.Map;

/**
 * 用「状态 × 事件 → 目标状态」的迁移表实现状态机。
 * 非法迁移直接抛业务异常，把散落各处的 if(status==...) 收敛到一处。
 */
public final class OrderStateMachine {

    private static final Map<OrderStatus, Map<OrderEvent, OrderStatus>> MACHINE = new EnumMap<>(OrderStatus.class);

    static {
        put(OrderStatus.WAIT_PAY, OrderEvent.USER_CANCEL, OrderStatus.CANCELLED);
        put(OrderStatus.WAIT_PAY, OrderEvent.TIMEOUT_CANCEL, OrderStatus.CANCELLED);
        put(OrderStatus.WAIT_PAY, OrderEvent.PAY_SUCCESS, OrderStatus.PAID);

        put(OrderStatus.PAID, OrderEvent.TICKET_SUCCESS, OrderStatus.TICKETED);
        put(OrderStatus.PAID, OrderEvent.APPLY_REFUND, OrderStatus.REFUNDING);

        put(OrderStatus.TICKETED, OrderEvent.APPLY_REFUND, OrderStatus.REFUNDING);
        put(OrderStatus.TICKETED, OrderEvent.EVENT_FINISH, OrderStatus.FINISHED);

        put(OrderStatus.REFUNDING, OrderEvent.REFUND_SUCCESS, OrderStatus.REFUNDED);
        put(OrderStatus.REFUNDING, OrderEvent.REFUND_REJECT, OrderStatus.PAID);
        // FINISHED / CANCELLED / REFUNDED 是终态，无迁移
    }

    private static void put(OrderStatus s, OrderEvent e, OrderStatus t) {
        MACHINE.computeIfAbsent(s, k -> new EnumMap<>(OrderEvent.class)).put(e, t);
    }

    /** 返回迁移后的状态；非法则抛异常 */
    public static OrderStatus next(OrderStatus current, OrderEvent event) {
        Map<OrderEvent, OrderStatus> map = MACHINE.get(current);
        OrderStatus target = map == null ? null : map.get(event);
        if (target == null) {
            throw new BusinessException(OrderErrorCode.ORDER_STATUS_ILLEGAL);
        }
        return target;
    }
}
```

## 7. 购物车（Redis Hash）

购物车只暂存用户想买的「场次+票档+数量」，**不锁库存**（真正锁库存在提交订单时，第 4 卷会把锁提前）。用 Redis Hash：key=`mars:cart:{userId}`，field=`{eventId}:{tierId}`，value=数量。

路径：`order/service/CartService.java`

```java
@Service
@RequiredArgsConstructor
public class CartService {
    private final RedisTemplate<String, Object> redisTemplate;
    private final EventTierMapper eventTierMapper;
    private final TicketTierMapper ticketTierMapper;

    private String key(Long uid) { return "mars:cart:" + uid; }
    private String field(Long eventId, Long tierId) { return eventId + ":" + tierId; }

    public void add(Long uid, Long eventId, Long tierId, int qty) {
        if (qty <= 0) throw new BusinessException(CommonErrorCode.PARAM_INVALID);
        String f = field(eventId, tierId);
        redisTemplate.opsForHash().increment(key(uid), f, qty);
        redisTemplate.expire(key(uid), Duration.ofDays(7));
    }

    public void updateQty(Long uid, Long eventId, Long tierId, int qty) {
        if (qty <= 0) { remove(uid, eventId, tierId); return; }
        redisTemplate.opsForHash().put(key(uid), field(eventId, tierId), qty);
    }

    public void remove(Long uid, Long eventId, Long tierId) {
        redisTemplate.opsForHash().delete(key(uid), field(eventId, tierId));
    }

    public void clear(Long uid) { redisTemplate.delete(key(uid)); }

    /** 读取购物车并关联出价格，组装给前端 */
    public CartVO myCart(Long uid) {
        Map<Object,Object> raw = redisTemplate.opsForHash().entries(key(uid));
        List<CartItemVO> items = new ArrayList<>();
        for (Map.Entry<Object,Object> e : raw.entrySet()) {
            String[] parts = e.getKey().toString().split(":");
            Long eventId = Long.valueOf(parts[0]);
            Long tierId = Long.valueOf(parts[1]);
            Integer qty = Integer.valueOf(e.getValue().toString());
            EventTier et = eventTierMapper.selectOne(Wrappers.<EventTier>lambdaQuery()
                .eq(EventTier::getEventId,eventId).eq(EventTier::getTierId,tierId));
            if (et == null) continue;
            TicketTier tier = ticketTierMapper.selectById(tierId);
            CartItemVO vo = new CartItemVO();
            vo.setEventId(eventId); vo.setTierId(tierId);
            vo.setTierName(tier.getName()); vo.setPrice(et.getPrice());
            vo.setQuantity(qty);
            vo.setSubTotal(et.getPrice().multiply(BigDecimal.valueOf(qty)));
            items.add(vo);
        }
        CartVO vo = new CartVO();
        vo.setItems(items);
        vo.setTotal(items.stream().map(CartItemVO::getSubTotal).reduce(BigDecimal.ZERO, BigDecimal::add));
        return vo;
    }
}
```

CartController（`/api/v1/cart`，全部 `@CurrentUser Long uid`）提供 add/update/remove/list/clear，方法参照第 2 卷观演人，略。

> 为什么购物车放 Redis 而不是数据库：读写极其频繁、临时性强、要过期，放内存最快；订单才落 MySQL。

```java
@Component
public class PriceEngine {
    /** 服务费规则：每张 10 元（学习期固定，生产可按票档比例） */
    private static final BigDecimal SERVICE_FEE_PER_TICKET = new BigDecimal("10.00");

    /**
     * 根据「服务端查询到的真实价格」计算金额，绝不信任前端传价。
     * @param lines 每条：数据库票档 + 购买数量
     */
    public OrderPrice calculate(List<PriceLine> lines) {
        BigDecimal total = BigDecimal.ZERO;
        int ticketCount = 0;
        for (PriceLine l : lines) {
            if (l.getQuantity() <= 0) throw new BusinessException(CommonErrorCode.PARAM_INVALID);
            total = total.add(l.getPrice().multiply(BigDecimal.valueOf(l.getQuantity())));
            ticketCount += l.getQuantity();
        }
        BigDecimal service = SERVICE_FEE_PER_TICKET.multiply(BigDecimal.valueOf(ticketCount));
        BigDecimal discount = BigDecimal.ZERO;   // 第6卷接入优惠券后在此扣减
        BigDecimal pay = total.add(service).subtract(discount);
        if (pay.signum() < 0) pay = BigDecimal.ZERO;
        return new OrderPrice(total, service, discount, pay);
    }
}
```

`PriceLine`（tierId, price, quantity）、`OrderPrice`（四个金额字段）为普通 POJO。

## 10. 下单 Service（幂等+算价+扣库存+事务，核心）

路径：`order/service/impl/OrderServiceImpl.java`

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class OrderServiceImpl extends ServiceImpl<OrderMapper, Orders> implements OrderService {

    private final EventMapper eventMapper;
    private final EventTierMapper eventTierMapper;
    private final OrderItemMapper orderItemMapper;
    private final OrderLogMapper orderLogMapper;
    private final CartService cartService;
    private final PriceEngine priceEngine;
    private final RedisService redis;

    private static final long ORDER_TTL_MINUTES = 15;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public String createOrder(Long userId, CreateOrderDTO dto) {
        // ① 幂等：同一用户 + 同一幂等号 直接返回已有订单，防重复提交
        if (dto.getIdempotentKey() == null || dto.getIdempotentKey().isBlank()) {
            throw new BusinessException(OrderErrorCode.REPEAT_SUBMIT);
        }
        String idemRedisKey = "mars:order:idem:" + userId + ":" + dto.getIdempotentKey();
        Boolean first = redis.setIfAbsent(idemRedisKey, "1", ORDER_TTL_MINUTES * 60);
        if (Boolean.FALSE.equals(first)) {
            // 可能是重复提交，尝试查已生成订单
            Orders exist = baseMapper.selectOne(Wrappers.<Orders>lambdaQuery()
                .eq(Orders::getUserId, userId).eq(Orders::getIdempotentKey, dto.getIdempotentKey()));
            if (exist != null) return exist.getOrderNo();
            throw new BusinessException(OrderErrorCode.REPEAT_SUBMIT);
        }

        // ② 校验场次可售
        Event event = eventMapper.selectById(dto.getEventId());
        if (event == null) throw new BusinessException(CommonErrorCode.RESOURCE_NOT_FOUND);
        LocalDateTime now = LocalDateTime.now();
        boolean saleable = (event.getStatus() == EventStatus.PRESALE.getCode()
                || event.getStatus() == EventStatus.ONSALE.getCode())
                && (event.getSaleStart() == null || !now.isBefore(event.getSaleStart()))
                && (event.getSaleEnd() == null || !now.isAfter(event.getSaleEnd()));
        if (!saleable) throw new BusinessException(OrderErrorCode.EVENT_NOT_SALE);

        // ③ 合并同票档数量 + 限购校验
        Map<Long,Integer> qtyMap = new LinkedHashMap<>();
        int totalQty = 0;
        for (OrderItemDTO it : dto.getItems()) {
            qtyMap.merge(it.getTierId(), it.getQuantity(), Integer::sum);
            totalQty += it.getQuantity();
        }
        if (totalQty > event.getLimitPerOrder()) {
            throw new BusinessException(OrderErrorCode.OVER_LIMIT);
        }

        // ④ 查票档真实价格与库存，组装算价行
        List<PriceLine> lines = new ArrayList<>();
        Map<Long, EventTier> etMap = new HashMap<>();
        for (Map.Entry<Long,Integer> e : qtyMap.entrySet()) {
            EventTier et = eventTierMapper.selectOne(Wrappers.<EventTier>lambdaQuery()
                .eq(EventTier::getEventId, dto.getEventId())
                .eq(EventTier::getTierId, e.getKey())
                .eq(EventTier::getStatus, 1));
            if (et == null) throw new BusinessException(OrderErrorCode.TIER_NOT_ON_SALE);
            etMap.put(e.getKey(), et);
            lines.add(new PriceLine(e.getKey(), et.getPrice(), e.getValue()));
        }

        // ⑤ 服务端算价
        OrderPrice price = priceEngine.calculate(lines);

        // ⑥ 扣库存（关键防超卖：条件更新，affected=0 则回滚）
        for (Map.Entry<Long,Integer> e : qtyMap.entrySet()) {
            EventTier et = etMap.get(e.getKey());
            int rows = eventTierMapper.deductStock(et.getId(), e.getValue());
            if (rows == 0) {
                throw new BusinessException(OrderErrorCode.STOCK_NOT_ENOUGH);
            }
        }

        // ⑦ 写订单主表
        Orders order = new Orders();
        order.setOrderNo(OrderNoGenerator.next());
        order.setUserId(userId);
        order.setEventId(dto.getEventId());
        order.setTotalAmount(price.getTotalAmount());
        order.setServiceAmount(price.getServiceAmount());
        order.setDiscountAmount(price.getDiscountAmount());
        order.setPayAmount(price.getPayAmount());
        order.setStatus(OrderStatus.WAIT_PAY.name());
        order.setIdempotentKey(dto.getIdempotentKey());
        order.setRemark(dto.getRemark());
        order.setExpireTime(now.plusMinutes(ORDER_TTL_MINUTES));
        baseMapper.insert(order);

        // ⑧ 写明细
        for (OrderItemDTO it : dto.getItems()) {
            EventTier et = etMap.get(it.getTierId());
            OrderItem oi = new OrderItem();
            oi.setOrderId(order.getId());
            oi.setEventId(dto.getEventId());
            oi.setTierId(it.getTierId());
            oi.setViewerId(it.getViewerId());
            oi.setUnitPrice(et.getPrice());
            oi.setQuantity(it.getQuantity());
            oi.setSubTotal(et.getPrice().multiply(BigDecimal.valueOf(it.getQuantity())));
            orderItemMapper.insert(oi);
        }

        // ⑨ 写状态日志
        saveLog(order.getId(), null, OrderStatus.WAIT_PAY, OrderEvent.USER_CANCEL, "CREATE", userId.toString());

        // ⑩ 清空购物车（也可只移除已购项）
        cartService.clear(userId);

        return order.getOrderNo();
    }

    /** 取消订单（仅 WAIT_PAY 可取消），释放库存 */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public void cancel(Long userId, String orderNo) {
        Orders order = getOwnedOrder(userId, orderNo);
        OrderStatus from = OrderStatus.valueOf(order.getStatus());
        OrderStatus to = OrderStateMachine.next(from, OrderEvent.USER_CANCEL); // 非法会抛异常

        // 释放库存：把已售(下单即扣)回补
        List<OrderItem> items = orderItemMapper.selectList(
            Wrappers.<OrderItem>lambdaQuery().eq(OrderItem::getOrderId, order.getId()));
        for (OrderItem it : items) {
            eventTierMapper.addStock(it.getEventId(), it.getTierId(), it.getQuantity());
        }
        order.setStatus(to.name());
        baseMapper.updateById(order);
        saveLog(order.getId(), from, to, OrderEvent.USER_CANCEL, "USER_CANCEL", userId.toString());
    }

    /* ---- 状态机迁移统一入口（支付等其它地方复用） ---- */
    @Transactional(rollbackFor = Exception.class)
    public void transit(Long orderId, OrderEvent event, String operator) {
        Orders order = baseMapper.selectById(orderId);
        if (order == null) throw new BusinessException(OrderErrorCode.ORDER_NOT_FOUND);
        OrderStatus from = OrderStatus.valueOf(order.getStatus());
        OrderStatus to = OrderStateMachine.next(from, event);
        order.setStatus(to.name());
        if (event == OrderEvent.PAY_SUCCESS) order.setPayTime(LocalDateTime.now());
        baseMapper.updateById(order);
        saveLog(orderId, from, to, event, event.name(), operator);
    }

    private Orders getOwnedOrder(Long userId, String orderNo) {
        Orders order = baseMapper.selectOne(Wrappers.<Orders>lambdaQuery()
            .eq(Orders::getOrderNo, orderNo).eq(Orders::getUserId, userId));
        if (order == null) throw new BusinessException(OrderErrorCode.ORDER_NOT_FOUND);
        return order;
    }

    private void saveLog(Long orderId, OrderStatus from, OrderStatus to, OrderEvent event, String remark, String operator) {
        OrderLog log = new OrderLog();
        log.setOrderId(orderId);
        log.setFromStatus(from == null ? null : from.name());
        log.setToStatus(to.name());
        log.setEvent(event.name());
        log.setRemark(remark);
        log.setOperator(operator);
        orderLogMapper.insert(log);
    }
}
```

`EventTierMapper` 增加两个「条件更新」方法（防超卖核心，用 SQL 保证原子）：

```java
@Update("""
    UPDATE show_event_tier
       SET sold_stock = sold_stock + #{qty}, version = version + 1
     WHERE id = #{id} AND total_stock - sold_stock - locked_stock >= #{qty}
    """)
int deductStock(@Param("id") Long id, @Param("qty") int qty);

@Update("""
    UPDATE show_event_tier
       SET sold_stock = sold_stock - #{qty}, version = version + 1
     WHERE event_id = #{eventId} AND tier_id = #{tierId} AND sold_stock >= #{qty}
    """)
int addStock(@Param("eventId") Long eventId, @Param("tierId") Long tierId, @Param("qty") int qty);
```

> **为什么这样能防超卖？** `WHERE total - sold - locked >= qty` 把判断和更新放在**一条 SQL** 里，InnoDB 行锁保证并发时排队执行，库存不足的请求 affected rows=0，业务抛异常并整体回滚。这是不依赖 Redis 也正确的做法；第 4 卷会把热点放 Redis 抗压。

```java

}
```

## 12. Spring 事务要点（必须理解）

1. `@Transactional(rollbackFor = Exception.class)`：Spring 默认只对 **RuntimeException** 回滚，加上 `rollbackFor=Exception.class` 让受检异常也回滚，避免踩坑。
2. **失效场景**（面试与实战高频）：
   - 同类中 A 方法没注解调用 B 方法有注解 → 事务不生效（自调用绕过代理）。解决：拆到另一个 Bean，或注入自身代理。
   - 方法不是 public、类没被 Spring 管理（没加 @Service）→ 不生效。
   - 异常在方法内被 try-catch 吞掉没抛出 → 不回滚。
   - 数据库引擎不支持事务（MyISAM）→ 用 InnoDB。
3. 本下单方法内：扣库存、插订单、插明细、写日志必须在**同一事务**，任何一步失败全部回滚（库存不会扣了却没单）。
4. 事务范围尽量短：不要在事务里发 HTTP、发短信；这些放到事务提交后（第 5 卷用 MQ/`TransactionSynchronization afterCommit`）。
